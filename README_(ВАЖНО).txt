О проекте

NetGuard - небольшая Windows-программа для блокировки выбранных сайтов через системный файл hosts.

На данный момент программа находится на стадии альфа-тестирования:

Версия: Alpha 0.1

Программа всё ещё имеет простой дизайн и пока не обладает всеми запланированными функциями, но основная функция блокировки сайтов уже работает.


Запуск программы

Откройте папку с NetGuard.
Перейдите в папку:
dist
Запустите файл:
NetGuard.exe
Обязательно запустите программу от имени администратора.

Это необходимо, потому что программа изменяет системный файл Windows hosts.

После запуска вы сможете включать и выключать блокировку сайтов.


Возможности текущей версии

✔ Блокировка сайтов
✔ Включение и отключение защиты
✔ Работа через системный файл Windows hosts
✔ Сборка в .exe

Ограничения Alpha 0.1

✘ Нельзя добавлять свои сайты вручную.
✘ В текущей версии заблокирован только:
max.ru

( Вы понимаете, почему именно он XD )

В следующих обновлениях планируется добавить возможность самостоятельно вводить адреса сайтов для блокировки.


После перезагрузки компьютера

Если оставить защиту включённой и перезагрузить компьютер, блокировка может перестать работать, потому что программа пока не запускается автоматически.

В будущих версиях планируется добавить:

автоматический запуск вместе с Windows;
сохранение состояния защиты;
улучшенные настройки.
