NetGuard (Alpha 0.1)

Блокируйте сайты в любых браузерах через простую Windows-утилиту.

Версия

NetGuard Alpha 0.1
Создано: Frutig0

Установка
Скачайте ZIP-архив приложения.
Распакуйте архив.
Откройте папку dist.
Запустите NetGuard.exe от имени администратора.

После запуска вы сможете включать и отключать блокировку сайтов.

Возможности

На данный момент NetGuard находится на стадии публичного альфа-тестирования.

Сейчас доступна основная функция:

Блокировка сайтов через системный файл Windows hosts;
Работа с любыми браузерами.

В текущей версии доступна блокировка только одного сайта:

max.ru

Это тестовая версия, созданная для проверки стабильности работы программы.

В будущем планируется добавить:

добавление собственных сайтов;
автозапуск вместе с Windows;
сохранение состояния защиты;
улучшенный интерфейс и дополнительные настройки.

Дисклеймер

NetGuard - это экспериментальный проект и первая программа автора на Python.

Программа изменяет системный файл Windows hosts, поэтому для работы требуются права администратора.

Используйте программу только на своих устройствах или с разрешения владельца компьютера.

Автор не несёт ответственности за возможные проблемы, связанные с неправильным использованием программы.
